# Test families

| Family | Purpose |
| --- | --- |
| unit | Node and contract helpers |
| component | Graph slices |
| contract | Input/result/event compatibility |
| replay | Historical runs remain reproducible |
| recovery | Resume after crash, lease loss, at-least-once delivery |
| concurrency | Duplicate, stale, conflicting writes |
| adversarial | Injection, unsafe requests, malicious tools |
| evaluations | Golden tasks, grounding, goal completion, cost, drift, model/tool swap |
