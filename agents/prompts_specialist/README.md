# Prompts specialist (`prompts_specialist`)

Writes future-surviving agent packages to `agents/<agent_id>/`.

Capability: `agent_package_authoring`. Invoke with `AgentTaskContract`. Goal is satisfied only when the package exists, matches `standards/future-surviving-agent.md`, imports `agent_kernel`, and has independent validators plus test family directories.

Does not implement product features. Does not emit markdown persona agents.
