# Agents

Packages written by [`prompts/promptsSpecialist`](../prompts/promptsSpecialist):

```text
agents/<agent_id>/
```

Each package is a durable goal processor: immutable task/result contracts, validated DAG planning, bounded concurrent execution, independent validators, repair, RuntimeBundle freeze, and evidence. Shared deterministic types live in [`agent_kernel`](../agent_kernel). The standard is [`standards/future-surviving-agent.md`](../standards/future-surviving-agent.md).
